# Panadería App

## Descripción
Panadería App es una aplicación móvil desarrollada en Android Studio utilizando Java y XML. Su propósito es permitir que los clientes conozcan la panadería y realicen un proceso de inscripción.

## Objetivo
Desarrollar una aplicación móvil que permita aplicar conceptos de programación Android, diseño de interfaces, navegación entre actividades y transferencia de información entre ventanas.

## Sector
Comercio y alimentos.

## Justificación
El sector de las panaderías es importante en la vida cotidiana. Una aplicación móvil puede facilitar la comunicación con los clientes y permitirles conocer los servicios disponibles.

## Funcionalidades
- Presentación de la panadería.
- Formulario de inscripción de clientes.
- Selección del tipo de servicio.
- Confirmación de inscripción mostrando los datos ingresados.
- Opción para salir de la aplicación.

## Ventanas de la aplicación
1. Presentación.
2. Formulario de inscripción.
3. Confirmación de inscripción.
